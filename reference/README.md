# Referensi sumber

- `image-manifest.json`: asal, ukuran, dan hash gambar yang pernah diimpor. Ini catatan historis, bukan daftar aset runtime; beberapa gambar yang tidak digunakan sudah dihapus dari `public`.
- `icomoon/selection.json`: sumber set ikon untuk diimpor kembali ke IcoMoon bila ikon perlu diedit. Font dan stylesheet yang digunakan aplikasi tetap berada di `public/assets/icons/icomoon`.

File pada folder ini mendukung pemeliharaan proyek dan tidak dimuat langsung oleh halaman aplikasi.
